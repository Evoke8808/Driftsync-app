Integration API v1

Plug SkillSetu into SAP SuccessFactors, Workday, a job portal or an NGO case tool. REST + JSON, an API key, signed webhooks and an OpenAPI spec (openapi.json).

1 · Auth

Send x-api-key on every call. Demo key: skillsetu-demo-key. Click Authorize below to try calls live.

2 · Try it
curl -X POST http://localhost:4004/integration/v1/createCase \
 -H "x-api-key: skillsetu-demo-key" -H "Content-Type: application/json" \
 -d '{"story":"I ran a tiffin service for 6 years and kept accounts","name":"Lakshmi"}'
3 · Flow

createCase → getMatches / getLearningPlan / getReadiness → submitForReview → counsellor approves → webhook case.approved → pushToSuccessFactors.

4 · MCP for AI assistants

Any assistant that speaks MCP (Claude, ChatGPT, SAP Joule) can onboard a person: tools onboard_person, add_to_story, find_jobs, make_learning_plan, check_filter_barriers, send_to_counsellor, get_case.

Web: POST /mcp with the same x-api-key. Claude Desktop: run mcp/stdio.js.
